### ✨ Core Experience

- **🌌 Liquid Glass Interface**: Full-bleed edge-to-edge hero spotlight with a dynamic frosted top bar and floating glass navigation dock.
- **🎬 Curated Global & Regional Discovery**: Seamless browsing across Trending, Hollywood, Bollywood, South Indian, K-Drama, and Anime catalogs with smart upcoming release badges.
- **⚡ Modular Addon Ecosystem**: Flexible support for external manifests, custom source resolvers, priority ordering, and encrypted backup/restore.
- **🎥 Pro Cinema Playback**: Hardware-accelerated high-bitrate playback with multi-audio support, Picture-in-Picture, and intuitive gesture controls (brightness, volume, seek, speed boost).
- **💬 Smart Subtitle Engine**: Instant multi-source subtitle matching, rich Bangla typography rendering, live sync/style customization, and AI-powered translation modes.

---

### ⚙️ Quick Setup

1. Install the latest **THIVO** release on your Android device.
2. Navigate to **Sources → Settings** inside the app.
3. Configure your personal API keys and preferred addons to unlock full catalog and subtitle capabilities.
